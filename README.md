Advanced Platformer: Part 2

Welcome to the second installment of the Advanced Platformer series! This project features smooth gravity physics, collectables and Keys and more levels as well as custom level design, and more than 700 blocks of Scratch code built from the ground up.

🎮 How to Play

• Movement & Jumping: Use your Arrow Keys to navigate through the levels and jump across platforms.
• Main Objective: Collect all the scattered apples to clear your path.
• The Lock & Key: Find and pick up the hidden key to unlock locked gates and pass safely through restricted platforms.

🛠️ Built With

• Engine: Over 700 blocks of scratch code handling complex physics, collision detection, and logic.
• Credits & Acknowledgments:
	• Griffpatch: Huge thanks for the gravity tutorials that helped shape the player movement and key mechanics.
	• Scratch Libraries: Sound effects and sprite assets sourced directly from the official Scratch Sound and Sprite libraries.
	• Creator: Designed, customized, and coded with love by me!
